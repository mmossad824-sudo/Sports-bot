# Yalla Live | يلا لايف - Sports Bot & Streaming Backend

هذا المشروع هو النظام الأساسي المتكامل لموقع "يلا شوت توداي" (الذي تحول لـ Yalla Live) الذي يعمل كخادم سحابي (Backend) على منصة Hugging Face. النظام يجمع الأخبار، يدير البثوث المباشرة عبر يوتيوب، وينشر التحديثات آلياً عبر منصات التواصل الاجتماعي.

## 🌟 الميزات الأساسية
- **البث المباشر التلقائي:** جلب المباريات المباشرة وإنشاء بثوث تفاعلية على يوتيوب عبر `ffmpeg`.
- **نظام الحماية من الحظر (Anti-Ban):** فلاتر متقدمة في ffmpeg (تمويه، تشويش صوتي، تقطيع) لتخطي حقوق النشر.
- **إدارة حدود يوتيوب (Protection & Limits):** البوت مضبوط لإنشاء **بث واحد فقط يومياً** للمباريات ذات الأولوية القصوى (فوق 80 نقطة) لحماية قناة يوتيوب الجديدة من الحظر.
- **إعادة استخدام البثوث (Quota Fallback):** إذا تم استنفاد حَد الـ API لإنشاء البثوث، يعود البوت ويستخدم بثاً مجدولاً مسبقاً (Ready) لتشغيله بدلاً من الفشل.
- **النشر التلقائي:** نشر الأخبار وأحداث المباريات على منصات (Facebook, Telegram, TikTok) بشكل آلي بروابط متكاملة.

## 🏗️ هيكل المشروع وأهم الملفات

- `main.py`: النقطة الرئيسية لتشغيل تطبيق FastAPI (يستقبل الـ Webhooks ويعرض حالة البث).
- `live_manager.py`: العقل المدبر لإدارة البثوث (تشغيل وإيقاف الـ FFmpeg، تقييم أهمية المباريات، مراقبة البث النشط).
- `youtube_uploader.py`: التعامل مع YouTube API (إنشاء البث المباشر، إنشاء الفيديوهات القصيرة Shorts، وتجديد الـ Access Token من خلال الـ Refresh Token).
- `social_bot.py`: يقوم بنشر الأخبار والتحديثات (الأهداف وغيرها) عبر قنوات التواصل الاجتماعي (فيسبوك، وتيليجرام).
- `scraper.py`: لجلب آخر الأخبار الرياضية من مصادر موثوقة (RSS).
- `video_processor.py`: لدمج ومعالجة فيديوهات الأهداف لإرسالها وتجهيزها كـ Shorts.
- `upload_match_highlights.py`: سكريبت لتحميل ملخصات المباريات أوتوماتيكياً.
- `frontend/`: المجلد الذي يحتوي على كود موقع الويب الثابت (HTML, JS, CSS). تم تحديثه ليشمل كل الروابط الجديدة.

## 🔐 نظام التوكنات (Tokens System)
النظام يعتمد بشكل كبير على متغيرات البيئة (Environment Variables). 
تم دمج توكنات يوتيوب بشكل دائم في الملفات لتجنب المشاكل (Client ID, Client Secret, Refresh Token) في `youtube_uploader.py`. 
باقي التوكنات موجودة في إعدادات السيرفر السحابي أو تقرأ من ملف `.env` (لوكال).

## 🛠️ كيفية عمل نماذج الذكاء الاصطناعي الأخرى (AI Instructions)
إذا كنت نموذج ذكاء اصطناعي مكلفاً بالاستكشاف، إليك أهم النقاط:
1. **عدم التعديل العشوائي** على متغيرات `MAX_YT_STREAMS_PER_DAY` أو `MIN_PRIORITY_FOR_YT` في `live_manager.py` إلا بموافقة المطور، حيث أنها حيوية لسلامة القناة.
2. الكود يتجاهل الملفات الكبيرة (الفيديوهات التجريبية والاختبارات) وهي غير مرفوعة في Git بواسطة `.gitignore` للحفاظ على مساحة الكود نظيفة.
3. لمعرفة حالة البث الحالية السحابية يمكن استخدام: `curl -s https://[HF_URL]/api/admin/stream_status`.
